# Turnia

Turnero para manicura/estética, peluquería y barbería. Web estática (HTML + JS) conectada a Supabase.

- `index.html`, `app.js`, `styles.css`: la app completa.
- Link público de reservas: `https://TU-USUARIO.github.io/turnia/?n=slug-del-negocio`
- Base de datos: proyecto Supabase "turnia" (la clave `sb_publishable_` es pública por diseño; la seguridad la dan las políticas RLS).
